# 進級試験 Anki デッキ(総括講義確認テスト 2026)

医学部の進級試験対策として、「総括講義確認テスト 正解と解説」PDF から、国試的な 1 対 1 知識の Anki カードを作ったものです。

> **免責**: AI(Claude)を使って半自動生成した個人の学習用教材です。**内容の正確性は保証しません。** 特に `進級::要確認` デッキと `unverified` タグのカードは、教科書・講義資料で必ず確認してください。大学の配布資料そのもの(入力 PDF とコメント原文の全文 CSV)はこのリポジトリに含めていません。

## 中身

| パス | 内容 |
|---|---|
| `out/shinkyu.apkg` | Anki 用デッキ(全科まとめ) |
| `data/cards/{科コード}.jsonl` | カード本体(1 行 1 カード、出自メタデータ付き) |
| `data/topics/` | 行ごとのトピック抽出結果(specificity, card_policy) |
| `data/depts.json` | 科名 ↔ 略称コード ↔ 元 PDF 名 ↔ **PDF の md5** |
| `review/{科コード}.md` | skip した行、コメントとの差分、要確認の理由、独立レビューの指摘、件数 |
| `COVERAGE.md` | 処理済み科目と未着手科目の一覧 |
| `docs/METHOD.md` | 抽出条件・作業手順・カードの規則 |
| `docs/VERIFY.md` | 出自を検証する手順と、生成 AI に読ませる検証プロンプト |
| `CLAUDE.md` | 生成時に AI に与えた指示書(原文) |
| `scripts/` | extract / validate / build ほか |

## 使い方

1. `out/shinkyu.apkg` を Anki でインポートする(`ファイル → インポート`)。
2. 再インポートしても、ノートの guid が固定されているため重複せず、学習履歴は保たれます。
3. デッキは `進級::{科名}`(根拠が明確なカード)と `進級::要確認`(数値・薬剤・遺伝子などを含む、または補完したカード)に分かれます。

## 未着手の科目

[COVERAGE.md](COVERAGE.md) を見てください(想定科目は作者の推測です)。

## 出自を検証したい人へ

[docs/VERIFY.md](docs/VERIFY.md) を見てください。各カードは「コメントのどの部分から作ったか(`basis`)」「コメント由来か補完か(`content_source`)」を持っています。手元の PDF と突き合わせて確認できます。

## 自分の PDF を追加する

`input/` に PDF を置き、[docs/METHOD.md](docs/METHOD.md) の手順に沿ってください(`pip install -r requirements.txt`)。処理済みかどうかは PDF の md5 で判定します。
