# 出自の検証方法

このリポジトリは、元の PDF やコメント原文の全文を含みません。検証には、**自分の手元にある同じ PDF** を使います。

## 1. 手元の PDF が同じものか確認する
```
md5 -q 循環器内科2026正解と解説.pdf     # macOS
md5sum 循環器内科2026正解と解説.pdf     # Linux
```
`data/depts.json` または `COVERAGE.md` の md5 と一致すれば、カードの根拠になった PDF と同一です。一致しない場合は、版が違う可能性があるため、内容を信用しないでください。

## 2. カードの読み方
`data/cards/{科コード}.jsonl` の 1 行が 1 カードです。

| フィールド | 意味 |
|---|---|
| `src_no` | PDF 内の問題番号 |
| `kokushi` / `origin` | 国試番号(出典タグ)/ 国試・オリジナル・不明の別 |
| `content_source` | `comment`: コメント由来 / `supplement`: 標準知識で補完 / `inferred`: 論点名から推測 |
| `basis` | `comment` の場合、コメント原文の連続部分文字列。PDF の該当番号のコメントにそのまま存在するはず |
| `note` | 補完した場合、何をどの根拠で補ったか |
| `risk_flags` | 数値・薬剤・遺伝子・ガイドライン依存・旧国試・改変・コメント不整合 |

## 3. 検証の手順
1. `content_source=comment` のカードを任意に選び、PDF の `src_no` のコメントに `basis` が含まれるか確認する。
2. `supplement` / `inferred` のカードが `進級::要確認` に入っているか確認する(本デッキに混ざっていれば不具合)。
3. `review/{科コード}.md` の「問題冊子がないと作れない行」(skip)と「元コメントとの差分」を読み、除外・修正の理由を確認する。
4. 国試番号から本文を思い出して作られたカードがないか確認する(1-hop ルール違反)。

## 4. 生成 AI に検証させる場合
PDF(またはそのテキスト)と `data/cards/{科コード}.jsonl` を AI に渡し、次のように依頼してください。

```
添付の「総括講義確認テスト」PDF と、cards.jsonl があります。次を検査してください。
1. content_source=comment の各カードについて、basis が PDF の src_no 行のコメントに
   連続部分文字列として含まれるか。含まれないカードを列挙してください。
2. カードの front/back が、コメントに書かれていない内容を含んでいないか(含む場合は
   content_source の誤りです)。
3. supplement/inferred のカードが、数値・薬剤の適応・遺伝子の記述を含んでいないか。
4. 国試的な標準知識として誤り・曖昧さがないか。
推測で補わず、確信が持てないものは「判定不能」としてください。
```

AI の判定も誤ることがあるため、指摘は教科書で最終確認してください。

## 5. 誤りを見つけたら
Issue に、カード id(例: `CV-07-a`)、問題点、根拠(教科書の該当箇所)を書いてください。
